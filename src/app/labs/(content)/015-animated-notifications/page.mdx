One of the missing features of Life of Plastic was a notification system
that created a log every time a piece of plastic went through a system.
I wanted to be able to show all the different processes and keep track
of how plastic moved. In the code there were many times that I could
have added an `addNotification()` that would build a string of
the event and save it to state. Then based on this array of strings,
I could use Framer Motion to add and remove notifications through an
animating feed.

1. Add state and buttons to add and remove items.
2. Render the state in a styled component.
3. Automatically remove the oldest item when the list is too long.
4. Animate the list to tick items in.
5. Limit the visible size of the list so it can be scrolled to find logs.
